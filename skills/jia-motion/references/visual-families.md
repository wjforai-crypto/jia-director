# 按画面逻辑选择制作方法

当前制作须先执行[王杰已采用的花叔13项规则](huashu-rules.md)及其明确适用范围；本文保留的旧方法、组件或历史案例不是豁免。新方向三构图选择为人工节点，流程图标红；已确认方向的常规修订不重复选型。

先决定观众要看见哪个事件，再选择绘制方式。下表是方法落位，不代表新后端全部在本机跑通。

| 画面类型 | 让内容发生的方式 | 实现选择 | 主要风险 |
|---|---|---|---|
| 界面/动态图形 | 同一对象伸展、重排；点击/拖动改变状态；构造图形后保留结果 | HTML/CSS/SVG＋确定性运动；本包工具可复用 | 容器和内容抢时间、假光标无因果、每镜整页清空 |
| 像素角色 | 准备姿势、行动、反应；低频姿势与平滑相机分开 | Canvas小画布、硬边整数缩放；CRT另作材质层 | 把整体掉帧当像素风；只有角色位置变化、没有表演 |
| 手绘角色 | 同一舞台中的目标、动作、反应；姿势/视线/道具共同表达 | Canvas或p5.brush；需当前本机实测 | 只抖笔触、角色站桩；照搬Clawd外形或无文字等风格禁令 |
| 版画/纸张 | 稳定构图、套色与尺度，物件完成动作后交给下镜 | SVG/Canvas/WebGL择需；Riso方法单独加载 | 把纹理当动作；把不适合该内容的“全片持续动”固化为规则 |
| 三维/空间机制 | 主体行为和空间事件；相机帮助理解路径、尺度与遮挡 | 优先现成Three.js/既有3D工程；复杂离线渲染另评Blender | 开工先写渲染引擎；相机转圈掩盖主体不动；低模近景暴露 |
| 原理/知识图解 | 同尺度对比、路径、因果、量的变化，回访同一对象 | SVG/Canvas；公式/几何有需要再选Manim | 画面只是字幕的背景；示意动画冒充真实仿真 |

绿幕人物/实拍作为输入时，归混合制作：明确素材负责什么、代码负责什么，再检查抠像与遮挡。本轮不调用生成视频API制作人物。

像素约10次/秒的姿势更新、无文字、固定弹簧、禁弹跳、连续运动等都只能是具体风格/作品的选择。通用层保留时间可重复、内容成立、来源清楚与真实审片。

本轮只用本包示例验证了界面和跨镜承接的局部实现；其他风格需要自己的代表段和验收。已有实拍剪辑能力保留，真实项目由王杰选制作方向。
