# 导演系统 · Jia Director 2.0

负责观众最终看到的结果。先判断这次任务与真实断点，再为当前镜头选择一个画法和真实工程。一个项目明确一个源码编辑者、最终时间线、字幕与音轨负责人；不要让每个工具各自再开一个导演流程。选题由王杰给定，已有选择与连续制作授权继续生效。

先读[已采用的花叔13项规则](references/huashu-rules.md)。这是王杰确认的制作约定，按适用范围和有依据的用户例外执行。尤其不要从旧案例推断蓝紫、通用代码小人、新方向三构图、重点字数或运动门槛已豁免。规则通过、技术通过、独立审核和王杰认可分别记录。

| 只研究或比较流程 | 只交方案、差异与证据，不自动起片 | [2.0流程图](assets/review/导演系统2.0流程.html)、[完整旧复核节点](references/full-workflow.md) |

“无口播”仍指无真人出镜口播，可含旁白。视频文件不自动等于A-roll，Canvas不是所有题材的默认答案。旧jia-video保留兼容，正式新任务只用本导演入口；jia-motion是制作模块。

## 导演先定什么

1. 锁定核心表达、事实数字、声音安排、画幅、时长、fps、交付物及当前授权。沿用已确认口吻和工程。事实证据不够时保留未确定项，不能绘制虚构证据。
2. 每镜写清背景、角色或道具、起始状态→触发/动作→结果、镜头理由、重点文字、字幕/证据正文及下镜承接。让角色和道具做事，不能只写“展示成长”“高级感”。见[分镜合同](references/director-2-runtime.md#分镜预检)。
3. 先表达，再选画法，再选工具。素材承担事实，代码解释机制或组织表现。保留原24风格家族与累计选择，先查具体子风格源码、函数、提示词和验证范围。复制demo的故事并换标题不算迁移。
4. 新角色或风格方向先出同一时点3种不同构图供王杰选；背景＋角色/道具＋动作分别说明。已选方向续改不重触发；AI代选必须已有授权并记录来源。
5. 先验最难的一段：角色姿态/接触、UI同一物变形、手绘实际笔触、三维空间/相机。静帧来自成片同一代码；实际2–6秒短段成立后扩片。人物按H05使用真实帧资产、手或背影；不临时加眼睛造通用角色。涉及生图时先规划动作覆盖与完整场景，不按固定图集格数备料。

## 运镜、动作与全片节奏

每次运镜回答：观众应看哪里？当前景别能否看清？这是引导还是重音？上一镜如何运动？稳定机位可以承载强动作和阅读；不要每镜同方向推近。

- 解释细节用缓推或横移，交代关系用拉远/尺度揭示；快推、砸入、甩镜对应少量明确揭晓。推进后有回到全貌、换景别或换注意对象的机会。
- 有重量的动作检查预备、执行、接触、结果和余韵；拿取、交接、碰撞、变形要核身份、支点、前后层与终态。位置平移和换表情不能替代角色表演。
- 艺术动画按H11设计主动作与两个相关母题循环。纹理保持媒介感，不能每帧重洗噪声冒充动作。像素角色的8–12fps姿势可与60fps粒子并存，输出fps与姿势频率分别声明。
- 开场3秒落在具体事件，结尾落在结果动作。按语义、音乐重音与阅读时长安排快慢；BPM不是切镜次数，不能为卡点截断必要条件或拉快原声。

## 逐阶段交付与失败回流

| 阶段 | 必须留下的东西 | 不成立时改哪里 |
|---|---|---|
| 内容/输入 | brief、锁定稿、事实与素材、声音与规格、真实断点 | 事实回来源，表达回脚本；缺不可替代输入说明缺口 |
| 分镜/选型 | 背景＋角色/道具＋动作、每镜时段、画法、重点字与字幕分列、三构图选择依据 | 先改分镜；运行storyboard预检清红灯再写代码 |
| 难点短段 | 同源静帧、可播放段、真实工程/依赖、明确问题 | 角色回资产，形变回对象，材质回画法，不用长片掩盖 |
| 逐镜/全片 | 场景源码、资源、事件时间、主/局部时间映射；一个最终时间线 | 剪辑返剪辑，动画返场景，声音返唯一音轨 |
| 工程输出 | 原生命令回执、实际采样与解码计数、MP4/透明MOV、源/spec/素材绑定 | 修资源、时间、字体和编码，不降低规格冒充通过 |
| 技术与实片审查 | 实绘文字audit、连续帧/乱序seek、切点邻帧、实际MP4、运动算法与版本；技术、动作表现、背景美术各自的结果与覆盖 | 红灯返修；黄灯逐项说明并看片；检查不能代签艺术接受 |
| 独立复核/冻结 | 绑定同一视频、源码、QA的独立记录，未解决问题阻断；冻结清单复验 | 改任一绑定文件就重跑相关QA和复核，不能复用旧PASS |
| 王杰审片 | 初稿完整看听→具体反馈→返修复测→第二稿 | 王杰确认具体版本、定稿与发布；AI不代签 |

[2.0流程图](assets/review/导演系统2.0流程.html)中红色节点是人工核验；AI发现实现缺陷应自行继续修，不能把每个工具运行都变成人工审批。原40个复核节点保留为详细索引，不作为每镜40次等待。

## 开工和交付都查：常见失败及修法

| 画面问题 | 具体修法 |
|---|---|
| 固定页眉、中心图、列表逐页淡入 | 按事件和因果重构镜头，减少无关框架；用户明确要清单/演示页时照需求 |
| 抽象词配图标；角色只沿线滑动 | 写对象、触发、姿态、接触和结果，先做真实动作短段 |
| 主体小、死背景、没有层次 | 对应缺陷调整尺度/遮挡/深浅和相关环境；不强迫所有远景和图表占半屏 |
| 只会快推、砸入、快切 | 重排重音与稳定阅读，换景别/运动方向；镜头内有真实变化 |
| 人物、道具、背景材质不一致 | 固定角色比例/色板/笔触，对照同一参考；艺术画法要调用实际材质函数 |
| 有证据原片却只画装饰图标 | 回原素材和语义选段，说明每条B-roll补什么；不把重画截图当证据 |
| 60fps文件、主体仍停住或抽搐 | 分清主时钟、姿势/粒子/笔触频率；连续取帧与乱序seek，排除复制帧和状态累积 |
| 开机/乱序seek画面不一致 | 检查缓存和随机种子、相机闭式时间；本机Canvas固定readback绘制方式，不放宽确定性 |
| 长中文出框、叠字、缺字靠系统回退 | 实绘audit和变体回归；修版式/补有许可字体子集，不缩成不可读小字 |
| 源码/spec已改却还用旧QA | 文件和帧目录逐一hash，重跑相关产物；交付verify拒绝陈旧回执 |
| 音频/词锚凭估计、透明段压出黑底 | 真实词表绑定原音轨；对齐采样帧与邻帧，验证实际alpha像素后回主时间线 |
| README写PASS却没看MP4 | 文件合同、实片审核、独立复核与王杰认可分别记录；完整看听覆盖单列 |

## 本机接入与渐进加载

本机2.0程序：`E:/开发项目/jia-director-system`。从本包执行`scripts/run-director.ps1 doctor`；旧原声剪辑和DotTTS继续用`scripts/run-video.ps1`及原配置，不重装模型/全局环境。具体命令、8语法、配方、材料函数、口播连接、冻结和自测见[2.0运行与接口](references/director-2-runtime.md)。

只读当前一个风格和当步接口，不把全部源码、Skill和负面清单反复塞进每镜提示词。短创作提示词交代目标、风格、可见事件、工程入口和交付；详细版再补角色/动作与验收。执行者保留造型和节奏创作空间，工程约束保持准确。

大型源码/字体/模型留项目目录。固定上游原文在vendor，可审计适配在runtime；本Skill提供导演要求与短入口。实际测试范围见项目`docs/2.0验收清单.md`，下载、源码绑定或单个短段不等于全部风格都已复现。新配方需H13原作与对照，>=80内部自评仍不等于王杰认可。

经验按issue→cause→fix→retest→destination登记，项目修复、配方候选、Skill候选分开；候选不自动晋升中央Skill。正式变更仍走中央管理器。上一入口原文保存在`ENTRY-1.3.1.md`，原参考、脚本与声音文档保留；冲突时以本入口和13规则为准。
