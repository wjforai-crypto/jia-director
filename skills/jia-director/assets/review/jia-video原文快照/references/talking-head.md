# 路线一：口播视频

以真人讲述、访谈或人物表达作为成片主线。目标是先剪清内容和原声节奏，再让补充画面帮助理解。详细执行使用 [原片剪辑流程](edit-source.md)，工具与合同使用 [运行说明](runtime.md)。

如果只有主题/脚本，先明确观点、事实、口语表达和拍摄要求，再由用户提供真实录制素材；不要将代码动画或合成配音冒充本人原片。现有原片已经足够时直接进入校对，不要求重新写稿或录制。

| 阶段 | 产物 | 审核点与失败后动作 |
|---|---|---|
| 目标、稿件与拍摄 | brief、必要的录制稿/拍摄清单，或现有素材信息 | 观点、事实、受众和口吻成立；有锁定文字时不擅改。 |
| 原片登记与转写校对 | 源文件哈希、参数、校对稿、原片时间索引 | 核查数字、否定词、条件、重录和歧义；ASR 只定位，疑点回听。记录实际全片核查覆盖。 |
| 语义粗剪 | 可播放粗剪、删改理由、原片→粗剪映射 | 观点完整、连接自然，不断章取义。先导出并审查，再进入精剪。 |
| 精剪原声与切点 | 精剪底片、SRT、粗剪→精剪映射与 QA | 不截尾音；呼吸、口型和停顿自然；有声底片本身已经成立。 |
| 补图与动效 | 绑定精剪输出时间的镜头表、素材与合成工程 | 先找可用素材；每个插入有信息任务；不遮脸、不重复字幕/原声。 |
| 整片审查与修订 | 初稿、检查记录、反馈与第二稿 | 内容、动作、声音、参数分开检查；用户确认才定稿。 |

主时钟是锁定精剪的输出时间。一个字幕 owner、一个最终音轨 owner；改词、改切点后更新受影响的映射。原声优先；新增配音另核实本人样本与试听，不能用默认声替换本人。

Skill 落位：选题由王杰给定，AI不默认搜题或换题；科技 AI 写稿可用 `jia-ai-writing`，其他中文及暂停保险子技能期间用 `jia-human-writing`；`local-content-research-v5` 取证与查资料，`editorial-review` 核事实与表达；本路线负责剪辑与交接，`hyperframes`/`gsap` 制作必要的局部动效，`data-visualization` 处理真实数据，`visual-acceptance` 查看成片实际画面。只加载当前阶段需要的 Skill。参考真人片可以由 `video-recreation` 提炼结构、节奏和补图方法，不能复制其观点或替代原片校对。

沿用 [验收](acceptance.md) 与现有版本合同：初稿待确认 → 用户反馈 → 修改与审片 → 第二稿待确认 → 用户确认定稿。已有连续执行授权内不额外添加每阶段人工等待；付费、本人声音试听和发布仍按实际授权处理。ChatCut 不进入本路线。

AI执行与人工复核按 [分工表](ai-human-review.md) 分开记录；视觉风格、动作规则及 HeiGe-Video / riso 等后端按 [风格落位表](style-routing.md) 选择。上游项目未完成本机安装与实际验收时只列候选，不宣称已能调用。
