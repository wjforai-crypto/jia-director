# AI执行、AI自检与人工复核

根据王杰2026-10-17明确要求，选题由王杰自己负责。接到选题后AI可查资料、补证、写稿与制作，不默认启动热点筛选或替换选题。人不必逐项批准常规操作，但人工责任不能由AI自查替代。

| 阶段 | AI执行与自检 | 王杰负责的人工环节 |
|---|---|---|
| 选题与目标 | 承接已给定主题，提示材料/事实缺口；被问到时才比较候选 | 自己定选题、立场、受众与要表达什么 |
| 研究与稿件 | 查原始来源，写脚本、核事实、标疑点；审校与写作分开记录 | 复核核心表达、关键事实及不能改的条件；按项目要求确认脚本 |
| 风格与规则 | 参考拆解，拟定design与motion规范，制作最能暴露问题的代表段 | 新风格/大改时定风格、红线和声音规则，查看代表段；认可后不每镜重复等待 |
| 真人原片 | 转写、回查、粗剪、精剪、导出和时间映射，先底片后补图 | 提供真实录制；保留的观点、语气或语义争议由本人确认 |
| 旁白 | 使用已确认声音逐句制作，回读查漏读误读，再以实际音轨定时 | 本人样本、准确原话与首次/新音色试听；口播原声不自动替换 |
| 画面与混音 | 按已定规则制作，检查素材、字幕、动作与声音事件 | 新风格代表段复核；已确认方向内不逐镜审批 |
| 初稿与二稿 | 渲染、解码、查看真实首尾及动作/切点，按反馈修改、复检 | 全片观看听审，给修改意见，再确认具体第二稿/定稿版本 |
| 封面与文案 | 按平台生成封面候选、标题、简介与检查记录 | 检查事实、标题承诺、平台目标与最终封面 |
| 发布与复盘 | 有明确授权时准备发布材料/填写页面、汇总真实数据 | 检查并决定发布；看数据决定下一期主题与方向 |

记录表分别使用AI已执行、AI自检覆盖、人工待复核、人工已确认（含真实用户回复/版本）。技术QA、ASR相似度或文件下载不能自动变成人工确认。

口播仍先校对→粗剪→精剪→补图；无口播仍脚本/声音→分镜与代表段→预演→制作。无口播不等于无旁白。用户授权连续制作时继续推进已授权步骤，不为每个工具增加人工等待。

若实际选择HeiGe-Video的资料转故事路径，按该项目当前真实脚本与素材方案确认门执行；仅把它列为候选不调用其脚本或伪填批准。付费、本人声音、新风格、用户定稿和发布按现有授权与实际复核分别判断。
