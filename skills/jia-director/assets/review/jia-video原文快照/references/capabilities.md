# 能力与职责

Jia-video 3.0是Agent串联本地工具的工作流入口，不是无需审片的全自动产品。以下状态还需本次doctor及回执核对。

| 能力 | 当前责任与边界 |
|---|---|
| 脚本/创意/素材成片 | 分镜、代表镜头、HyperFrames/GSAP或已有Remotion、合成；无A-roll用独立工程，不伪登记原片；尚非核心全自动编排 |
| 粗剪/精剪/补图 | 本地ASR人工校字、逐词面板、波形与恢复；粗剪/精剪底片、字幕与映射分别保留；帧级切点及第03步合成 |
| video-talkcraft词表/EDL | 原创文件桥保留；上游PolyForm非商用及未启用状态保留，不称商用已授权插件 |
| 本人声音 | DotTTS SOAR/audio.cpp本地runtime验通、样本建档、逐句合成及识别回读；声纹相似度/试听待本人确认；MOSS仅显式兼容 |
| 图片 | 当前宿主内置工具优先；Codex=image_gen，缺工具不虚构或偷偷换模型 |
| 动效 | 镜头执行层、8类局部组件、475条案例参考、GSAP、外部motion-archive；475不是可执行组件数 |
| 数据动效 | LiveCanvas趋势折线；原生1080×1440/30fps/3秒，需按画幅重排，不称所有图表自动可用 |
| 网络取材 | Commons/NASA公开搜索和选定下载，Mixkit指定Free详情页720P下载；其他站正常下载后导入，无key站不假称已连接 |
| 本地素材库 | SHA去重、来源/许可/标签、完整解码、坏缓存拒绝、选段sidecar和补图导入；在线响应缓存未实现 |
| 中文视觉检索 | VideoSeek独立进程，候选与时段；缺素材也可能误配，需审片 |
| 视频生成 | MiniMax已有核心桥/鉴权快照，自动付费关闭；旧任务10元上限不自动成为新任务授权 |
| QA与交付 | 参数/SHA/全流解码/首尾与切点帧/声音指标；实际看听、用户定稿和发布分别记录 |

工程拥有主时钟、字幕、最终音轨；素材库供应文件/来源/入出点，VideoSeek检索，动效输出镜头或插入，本地声音输出音频与实际cue。只有一个Skill入口，不装重复成片流程。

模型/依赖在工作区runtime，许可素材在`E:\视频素材库\Jia-video`，动效库在`E:\动效资产库\motion-archive`，工程交付在`E:\视频文档`。Skill保留小型代码/模板/索引、调用入口与阶段说明，不含录音、key、库存原视频或模型。
