# 路线二：无口播视频

以动画、产品演示、录屏、实拍/资料素材、图片或画面叙事作为成片主线，不依赖真人出镜口播。允许旁白、音乐、音效或无声；声音方式从 brief 确定。详细制作使用 [脚本与素材制作流程](create-video.md)。

| 阶段 | 产物 | 审核点与失败后动作 |
|---|---|---|
| 输入与参考拆解 | brief；如有参考，包含时间码、镜头/动作、风格和覆盖缺口的拆解包 | 实际看到视频；参考中的事实、商业结果、声音和素材不自动获得复用权限。 |
| 脚本与事实 | 事实表、脚本、核心表达 | 一镜一个主要信息任务；参考风格服务新主题，不能只换标题。 |
| 声音与分镜 | 正式旁白或音乐/阅读时钟、分镜、design | 旁白作品以实际音频定时；无声作品以阅读和事件定时；不强制背景音乐。 |
| 代表段与整片预演 | 关键难点代表段、完整可播放预演 | 查看动作中间态、跨镜承接、阅读时长与叙事。问题回到分镜或导演设计。 |
| 镜头资产制作 | 代码工程、复用素材、图片、必要生成片段 | 实拍/官方资产优先；精确数字汉字用代码排版；生成只填真实缺口。 |
| 统一合成与整片审查 | MP4、源码、资产清单、技术 QA、实际视听检查范围 | 一个时间线/字幕 owner/音轨 owner；实际首尾、切点和全片内容成立。 |
| 用户反馈与修订 | 新版本第二稿、变更与复检记录 | 用户明确确认后定稿；发布独立授权。 |

参考片存在时先调用已启用的 `video-recreation`，接收 reference-analysis、镜头表、动作与风格约束、原创迁移方案和镜头提示词。随后由本路线拥有实际制作。没有参考片时直接从主题/脚本开始，不强制反推。

技术按任务选择：HyperFrames + GSAP 作为本机已有的 HTML/代码动效底座；已有 Remotion 工程及数据图表复用当前验证运行时；数学公式可评估 Manim；笔刷/手绘可评估 p5.js+p5.brush；复杂 3D 可评估 Three.js/Blender；MV 可评估 librosa 提取节奏。后四类按当前环境复核，不能把可选项目称为已安装。需要连续真实动作且现成素材/静图/代码都不足时，才评估获授权的生成视频。

Skill 落位：选题由王杰给定；研究、写稿和审校按需调用现有内容 Skill；`video-recreation` 负责参考拆解与迁移；`video-shotcraft` 为产品片选择镜头配方；`hyperframes`/`gsap` 实现与渲染；`data-visualization` 管真实数据表达；图片默认使用当前宿主内置工具；`visual-acceptance` 辅助真实画面验收。音频技术指标不等于听审。

没有真实 A-roll 时使用本地独立渲染工程，不伪造原片推进核心状态；保留源码、媒体哈希、来源与版本。已有连续录屏/实拍需要剪辑时，可复用 [剪辑子流程](edit-source.md) 的校对、粗剪、精剪和映射能力，再返回本路线合成，不另建第三条生产路线。

本人旁白需要真实样本、准确原话和用户试听；未就绪时保留缺口，可以先推进无关镜头。付费生成按实际模型、预算、项目合同执行。ChatCut 不进入本路线。

AI执行与人工复核按 [分工表](ai-human-review.md) 分开记录；视觉风格、动作规则及 HeiGe-Video / riso 等后端按 [风格落位表](style-routing.md) 选择。上游项目未完成本机安装与实际验收时只列候选，不宣称已能调用。
