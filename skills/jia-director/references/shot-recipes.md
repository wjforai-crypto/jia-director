# 镜头配方选择

当前制作须先执行[王杰已采用的花叔13项规则](huashu-rules.md)及其明确适用范围；本文保留的旧方法、组件或历史案例不是豁免。新方向三构图选择为人工节点，流程图标红；已确认方向的常规修订不重复选型。

先读 [导演与运动判断](motion-direction.md)。下表是按任务选择的镜头方法，不是全都已自动实现的效果保证。先设计起态、动作中段、落态及跨镜承接，结果帧检查只是其中一项。连续主体与分层运动的已有实现见 [镜头执行层](directed-runtime.md)；[8类组件](motion-components.md)用于局部辅助及兼容。动画不依赖随机累积状态、墙钟或网页滚动。

## 高频候选

| 信息任务 | 画面与动作 | 适用检查 |
|---|---|---|
| 解释因果 | 同一物体经历触发、变化、后果；跟随或局部揭示让下一责任出现 | 动作能解释信息；起/中/末有不同状态；不靠标题换页 |
| 延续与补位 | 前一来源停止，后续事件继续；另一来源按条件进入同一路径或接收面 | 来源身份、条件和后果清楚；不把补位画成无条件恢复原状 |
| 对比/取舍 | 同尺度/同单位下观察同一对象的不同状态；必要时保留图表 | 指标事实有来源，比较对象一致；不是每句转成一张并列表 |
| 动作转场 | 在主动作中保持物体、方向或视点，从局部进入新空间 | 承接端点及适当动量；不默认所有层同时退场再入场 |
| 软件操作/产品证据 | 真实录屏或产品素材，裁切与焦点引导，重要结果留足阅读时间 | 能辨认操作和实际结果；生成 UI 不替代真实证据 |
| 口播解释插入 | 原声连续，必要时画中画；卡片/玻璃层用于承载结构，完成退场回到真人 | 避让人脸/字幕；每次插入有具体解释职责；粗剪/精剪已稳定 |
| 情景或氛围 | 用户素材或已获授权的生成镜头，保持人物、场景、方向和风格连续 | 不误当事实照片；候选 take 真正回看，未验通的生成器不调用 |

历史已认可的玻璃层、卡片动作和完整尾帧可以作为局部回归参考，要找到真实工程和认可记录；不能把所有历史输出算作获认可。用户指出寿险图形版像PPT后，该版仅保留功能与技术参考，不能继续作为整片风格模板。没有个人认可风格时，由本片用途设计短代表段并实际看片。

## 外部研究的使用方式

本工作区 `视频剪辑Skill-外部资料学习与增量补足.md` 和 `research/2026-10-03` 保留 LiveCanvas、awesome-opus5-5-videos 与公众号学习证据。它们用于检索构图、动作链和镜头职责，不是效果、价格或模型能力承诺。本包1.1新增可携带的原指南、源码模板与案例索引，详见 [motion-library.md](motion-library.md)，离线检索不再依赖研究目录；完整研究仍留在原位置。

需要借鉴具体例子时，读取对应源码/提示词并区分原作、重制与我们的实现。自建配方只有在保存可运行源码、输入、运行版本与最终文件检查之后，才标记为本机已验证配方。
