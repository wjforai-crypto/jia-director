# 动作与镜头的创作审查

适用于新制作或大改的代码动效、解释插入及混合镜头。技术检查沿用 [acceptance.md](acceptance.md)；本文件补充它无法判断的镜头和叙事问题，不代替用户评价。

## 先看连续段，再看三态

以实际可播放片段检查观看顺序、事件推进和镜头衔接，再从最终MP4提取主动作前、中、后状态。只看结果帧会漏掉同步入场、瞬移、持续滑动和动作中途消失。不能用背景有位移、文字有渐入或大量不同帧哈希证明主体动作讲清了信息。

审片记录直接写看到了什么以及为何影响理解：

| 检查 | 合格证据 | 应修改的表现 |
|---|---|---|
| 信息由动作承载 | 起/中/末对象发生可说明的状态变化，正文只是补名称/条件 | 去掉标题后只剩装饰漂移；流程仅是卡片挨个亮起 |
| 注意力与空间 | 主体先后明确，近远/遮挡/局部揭示让观看重点可追踪 | 每层同起同停；相机动时全场像贴在一块平板上 |
| 动作与受力 | 加速、接触、变化、余韵与本镜的原因一致 | 名义弹簧其实只换缓动；碰撞时停死或全屏乱抖 |
| 跨镜承接 | 物体、方向、视点或声音把事件接过去，必要的切镜理由清楚 | 事件尚未结束就整页清空，再弹新标题；相同主体无故换位置/身份 |
| 文案与事实 | 关键条件和主体在合适时刻可读，隐喻不扩大承诺 | 金额/比例无来源；身故受益人变成所有家属；压力全消失 |
| 声音与节奏 | 对应实际语义或已选择的音轨；动作落点有依据 | 最后随手配BGM硬卡；无声授权下添加音轨；尾音被截 |
| 结论与稳定 | 需要读的信息有完整稳定区间，结尾不截断 | 为“不能静止”持续抖字；为了停留把整片变成静态页 |

不设置所有视频统一的切镜秒数、运动百分比、五层数量或特效数量。图表和对照有明确工作时可以全屏、稳定；问题是无论主题都重复使用同一页式结构。

## 针对“像PPT”的回看

把整片结构写成观看顺序与每段承担的任务。如果只剩“标题A＋图→标题B＋列表→标题C＋表”而未讲清内容，回到分镜选择适合的演示、证据、对象变化或更好的文字组织，再检查其实现；不要求所有主题都安排贯穿角色。

检查相邻镜头是否总是相同视距、相同标题位置、相同中心图形与相同淡出。找出观众的视点何时被主体带走、何时一个动作被另一对象接住。不能靠把所有卡片做弹性入场或增加随机粒子来通过这一项。

提出具体修改，例如：保留同一账单随责任时间前进；相机跟随资金到新露出的生活场景；合同接收动作触发局部环境反应；把对照从整页表格改为同物体在两条件下的状态。不要只写“更高级”“更流畅”。

## 执行证据

- 任意seek复核：按顺序、直接跳转、反向回到同一关键时间，比较实际可见图像。纯函数或确定性的轨道不能依赖上一帧累积；隐藏子节点的状态差异也要确认不会在父层恢复后泄漏。
- 相机与动量：在物体/镜头承接前后查看邻帧。应连续时，位置和运动方向不跳变；声称速度连续时用实际运动或数值导数核对，而不是仅相同端点。
- 物理/光层：改变持续时间或大小后再看受影响动作，确认重力、弹性及接收面仍有对应关系。不要把视觉近似称作刚体、流体或科学仿真。
- 标签：本包builder检查可见文本；手写工程检查实际DOM/SVG文字，图片和视频里的既有字需要实际查看。视频禁止制作状态标签，文件名/QA可以记录版本。
- 记录最终MP4时间点、实际查看范围、问题、修订版和复核结果。自动 `framesViewed:false` 的报告不得冒充人工看片证据；另写实际视觉审查记录。

## 与两通路的关系

口播的真人反应与自然停顿本来就是镜头内容，不为了通过动效审查强塞运镜或全屏动画。粗剪、精剪先成立，再对新增解释层做以上检查。纯代码片需要用事件和空间建立观看过程；已有媒体合成只对本次新增或修改的段落复核，不无故扩大验证。

分别报告技术结果、本地创作审查和用户确认。生成了试验段只证明该动作/接口可运行；下一条完整视频仍要按真实脚本、素材和声音验收，不把一段验证样例当成用户认可风格。
