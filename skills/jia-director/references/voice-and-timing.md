# 声音决定时间，画幅决定构图

在有声动画和多画幅交付时读取。口播用本人原声；新增旁白按 [personal-voice.md](personal-voice.md) 使用本地优先的明确本人片段与准确原话建档、逐句合成及本地识别回读。模型/运行器验通与本人样本合成、实际试听分别记录，生效引擎与 CPU/GPU 验证以 doctor 当前读回和实测回执为准。Huihui 仅明确的离线试读，不冒充本人，性质放交付文件，不能上屏制作状态标签。

## 节奏进入镜头设计

有音乐时先从已选择的真实音轨确定BPM或拍点，标明速度是否恒定及重要落点；`60/BPM`只是恒定拍速的秒数换算，不代表已检测整首歌。主动作的接触/转换命中选定落点，准备可略早、余韵可延后，不机械每拍切镜。SFX只在有相应可见接触或内容用途时安排，不能最后随机铺一层。

有口播时语义、呼吸与实际字词先于节拍，不牺牲自然表达硬卡BGM。无配音/无音轨的任务使用阅读和事件节奏，不自动加TTS、音乐或假BPM。分镜记录哪些动作服从声音、哪些服从观看和阅读；主从层延迟仍可使用同一总时间轴下独立的局部轨道。

## 从实际音轨安排动画

1. 将锁定台词拆为有意义的语句单元，保存原句、音频资产和用途。测量每条实际音频时长，记录开口、尾音、停顿；ASR 只帮助定位，校对后才用于字幕。
2. 使用输出时间：`voiceStart` 为该句在全片开口的位置，`voiceEnd` 为实际尾音，镜头边界另计。片头引导、段间转场和结尾阅读停留均为制作选择，不能把它们算成音频时长。必要时按 `ceil(end * fps) / fps` 向上对齐帧，避免截掉尾音。
3. 将句子分配到镜头和动效，先出现提问，条件、对象、结果按真实语句建立。数值图不能在结论前完整泄露所有重点。背景图可以缓慢变化；主要文字应留出稳定阅读阶段。
4. 长字幕按语义拆句或换行，复核声音边界。只有句级时间就交付句级字幕，不能均分文字后标作逐词准确对齐。指定一个字幕 owner 与一个最终音轨 owner，分轨保存对白、旁白、BGM/SFX，统一全片 cue 和混音，切镜不截旁白或重复叠播原声。
5. 改台词、速度或声音后重测受影响的音轨和 cue，再导出新版本。正式声音替换试读后，旧镜头时长和字幕不自动有效。

逐句 batch 的 `cue.json` 使用实际 WAV 时长和明确段间停顿，先检查 `qa.json` 与 `batch.receipt.json`；ASR 有差异、不可用或第二次仍失败的句子保留为候选，不凭音频能播放就安排正式时间线。坏句单独换 seed 重做后，重新测量该句及后续受影响的 cue；当前没有跨批 resume，不能声称旧批次会自动更新。ASR 回读只辅助核对锁定文字，不能证明词级时间、音准、音色相似度或情绪已经合格。

## 横竖版共用内容，分别布局

- 同一脚本和已测声音可以复用；对横竖版分别设置画布、镜头参数、图像裁切和字幕区。不能仅缩放整张竖版画面来宣称横版已适配。
- 横版可用左右关系解释，竖版按上下阅读组织；保留共同的事实、重点与颜色语义。先检查最密镜头和最长字幕，再推广到全片。
- `build-motion.mjs` 提供画幅感知的基础布局。设置适合实际项目的 `captionReserve`；成片仍按人脸、硬字幕、平台遮挡和图表脚注检查。模板预留区只是起点。

## 声音测量与最终复核

使用现有 `normalize-audio.mjs` 对新文件处理并保留测量回执；它不生成旁白、不判断声音自然，也不修复错误剪口。核对实际输出的响度、真峰值、采样率和音视频时长。不能对已接近峰值的音轨只加大固定增益；应按现有工具过采样、补偿延迟、限制峰值，并重新测量新文件。

用 [inspect-video.mjs](media-inspection.md) 提取最终 MP4 的转场邻帧和尾帧；有合法核心项目时另做 `qa-media`。音频指标和转写不能代替听审，交付写清声音来源、本人音色建立状态、实际听审范围和剩余问题，不再次把已选择的本地路线报为尚未选择。
