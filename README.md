# 导演系统 · Jia Director

王杰的视频生产 Skill 发布仓库，包含总导演 `jia-director` 与原创动画模块 `jia-motion`，当前版本 **2.0.1**。

总导演承接口播、素材剪辑、原创动画、混合制作与参考复现；动画模块负责具体镜头的对象行为、角色动作、画面实现和验证。现有工程保持一个主时间线和最终输出负责人。

## 这次更新

- 生图前先按动作准备连续姿态或分层部件，明确图片与代码各自承担什么；图片数量按镜头需要决定。
- 分别声明输出fps、姿态更新节奏和主体实际动作，正常速度验证动态代表段。
- 风格帧与代表段包含完整背景，核对人物/背景的材质、空间、光影和遮挡。
- 技术、动作表现、背景美术分别审查；局部穿帮修复不能代替整片创作审查。

细节见 [2.0.1更新说明](docs/2.0.1.md)、[导演入口](skills/jia-director/SKILL.md)和[动画入口](skills/jia-motion/SKILL.md)。

## 本机使用与维护

已启用的客户端使用 `jia-director` / `jia-motion` 名称调用。正式个人 Skill 源仍由本机中央库管理；本仓库是审核后的版本化发布副本，不作为第二个实时维护源。安装或更新应由中央管理入口先隔离、审查、校验，再更新和同步客户端。

入口脚本目前依赖既有 Windows 本地导演程序、视频工作区和运行配置；这些外部依赖不在此 Skill 仓库中。克隆本仓库可完整阅读两份 Skill，但不代表另一台机器已具备渲染环境。运行方式见各 Skill 的 `references/director-2-runtime.md`。

## 发布范围与验证

两份包除中央治理生成的根 `inspection.json` 外完整保留；源文件哈希见 [packages-manifest.json](packages-manifest.json)。本次修改文档与交接模板，未更改渲染程序，也未重制或重新验收历史视频。已检查包格式、改动范围、同源规则一致性及中央同步；动作/背景的实际改进仍须通过后续真实试片验证。

原有上游署名、许可证和适用边界随包保留。第三方素材与工程的权利按各自声明处理；本次未为整包新增统一对外许可证。
