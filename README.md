# 导演系统 · Jia Director

王杰的视频生产 Skill 发布仓库，包含总导演 `jia-director` 与原创动画模块 `jia-motion`，当前发行版 **2.0.2**（`jia-director` 2.0.2，`jia-motion` 2.0.1）。

总导演承接口播、素材剪辑、原创动画、混合制作与参考复现；动画模块负责具体镜头的对象行为、角色动作、画面实现和验证。现有工程保持一个主时间线和最终输出负责人。

## 2.0.2安全修复

LiveCanvas渲染模板的间接依赖`source-map-js`从1.2.1更新至1.2.2，修复[GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)。主模板和历史快照均已修复；Remotion、React与画面源码未改，上游来源和原锁文件哈希继续保留。详见[2.0.2修复与升级方法](docs/2.0.2.md)。

发布检查新增离线版本回归检查及GitHub Actions双模板依赖审计。更新Skill不会自动修改已复制工程的依赖，已有工程按修复说明更新后执行`npm ci`与`npm audit`。

## 2.0.1制作规则

- 生图前先按动作准备连续姿态或分层部件，明确图片与代码各自承担什么；图片数量按镜头需要决定。
- 分别声明输出fps、姿态更新节奏和主体实际动作，正常速度验证动态代表段。
- 风格帧与代表段包含完整背景，核对人物/背景的材质、空间、光影和遮挡。
- 技术、动作表现、背景美术分别审查；局部穿帮修复不能代替整片创作审查。

细节见 [2.0.1更新说明](docs/2.0.1.md)、[导演入口](skills/jia-director/SKILL.md)和[动画入口](skills/jia-motion/SKILL.md)。

## 本机使用与维护

已启用的客户端使用 `jia-director` / `jia-motion` 名称调用。正式个人 Skill 源仍由本机中央库管理；本仓库是审核后的版本化发布副本，不作为第二个实时维护源。安装或更新应由中央管理入口先隔离、审查、校验，再更新和同步客户端。

入口脚本目前依赖既有 Windows 本地导演程序、视频工作区和运行配置；这些外部依赖不在此 Skill 仓库中。克隆本仓库可完整阅读两份 Skill，但不代表另一台机器已具备渲染环境。运行方式见各 Skill 的 `references/director-2-runtime.md`。

两份包除中央治理生成的根 `inspection.json` 外完整保留；源文件哈希见 [packages-manifest.json](packages-manifest.json)。2.0.1修改文档与交接模板；2.0.2仅修复模板依赖、更新来源记录并增加依赖检查，已在独立目录完成全新安装、类型检查、3秒实际渲染和完整解码。历史视频没有重制或重新验收；动作/背景的实际改进仍须通过后续真实试片验证。
