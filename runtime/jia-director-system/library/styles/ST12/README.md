# ST12 线稿透明水彩
主用途：人物故事与角色叙事

## 可复用规则
- 线与水彩保持可辨的层次
- 纸白是画面的一部分
- 颜料边缘、渗色和颗粒有一致尺度

## 保留的子风格
- L15钢笔速写：细棕墨线、错位罩染与纸边溶解
- O63铅笔日记：压力变化、页边批注与透明水彩
