# ST02 纸面信息讲解
主用途：知识科普与数据解释

## 可复用规则
- 镜头移动服务论证顺序
- 颜色承担固定信息角色
- 工程尺寸与图表数值各按自己的数据规则校核

## 保留的子风格
- L02工程简报：真实照片、尺寸线、磁贴与整墙回看
- L14白板：记号笔逐笔写画、擦除与区域行进
- L32数据叙事：真实数据、纸面图表和数值驱动动作
