# ST10 复古印刷图像
主用途：人物故事与角色叙事

## 可复用规则
- 纸张与油墨分别定义
- 铜版画以线造明暗
- 石印以色版和网点造明暗

## 保留的子风格
- L23铜版画：粗细变化的刻线、交叉排线与后上色
- O43石印海报：有限色版、分级平涂、粗网点与套色偏移
