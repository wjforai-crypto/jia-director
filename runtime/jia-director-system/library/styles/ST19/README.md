# ST19 像素动画与 16-bit RPG
主用途：人物故事与角色叙事

## 可复用规则
- 原生像素分辨率与最近邻放大
- 每个分支单独锁定色板和后处理
- 对象和文字遵守同一像素网格

## 保留的子风格
- L41：16-bit RPG、索引色、菜单与存档；该分支不加CRT滤镜
- M14：像素MG、角色动作与可选显示后处理
