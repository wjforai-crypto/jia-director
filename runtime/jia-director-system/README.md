# Jia Director execution program

This is the portable publication copy of the local director execution project.
It contains the Python CLI, animation renderer and local rendering assets,
storyboard validation, audio-word alignment, composition, QA and delivery contracts.
**TTS and voice-cloning implementation are excluded from this upload.**

From the repository root, read [安装与使用](../../docs/安装与使用.md), run
`pwsh -File scripts/setup.ps1`, then `pwsh -File scripts/smoke.ps1`.

The canonical Skill package is under `skills/jia-director`; the runtime adapter is
`scripts/director.ps1` at the repository root. The clone can live at any Windows path;
the author's original E drive and private workspace are not required.

`vendor/huashu-art-motion` retains selected upstream source and its original MIT,
font and third-party library notices. Its upstream lock records the original
snapshot; see `runtime-exclusions.json` at the root for files deliberately omitted.
`runtime/huashu` is the adapted execution copy. Source provenance and portable
changes are recorded in `runtime-source-manifest.json`.

24 style families are navigation and public source links. A navigation entry does
not mean every reference, external source archive or reference film is included.
Machine-local style bindings are generated by setup; no past user acceptance is copied.
