# 安装与使用 · 公开运行包

此前只有Skill说明；本次补齐导演执行程序、视频剪辑工作区、剪辑状态核心和配置入口。
**按王杰要求，本次不上传TTS、配音/音色克隆实现、模型或声音参考。**
现有音视频的原声剪辑、ASR、词锚、字幕映射和音轨合成保留。

## 下载

```powershell
git clone https://github.com/wjforai-crypto/jia-director.git
cd jia-director
```

也可点击仓库的Code → Download ZIP。目录名和盘符不必与作者相同。
目前验证目标是Windows＋PowerShell 7；没有声称macOS/Linux实机验通。

## 基础环境

先安装PowerShell 7、Python 3.12、Node.js 22或更新版本、FFmpeg（包含ffprobe），使其命令可用。
参考官方入口：[PowerShell](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows)、
[Python](https://www.python.org/downloads/windows/)、[Node.js](https://nodejs.org/en/download)、[FFmpeg](https://ffmpeg.org/download.html)。

在仓库根目录执行：

```powershell
pwsh -NoProfile -File scripts/setup.ps1
pwsh -NoProfile -File scripts/smoke.ps1
```

setup只在本仓库建立`.venv`、`node_modules`、`.local/browsers`与本机配置；会联网下载依赖与Chromium，
不会安装中央Skill、修改全局Python、调用文生视频或请求付费配音。
Skill由接收者自己使用客户端支持的受审安装方法启用，执行程序由根目录入口调用。

已有兼容Chromium可减少下载：

```powershell
pwsh -File scripts/setup.ps1 -Python python -BrowserPath 'C:/你的浏览器/chrome.exe'
```

`-SkipInstall`仅供依赖已安装时生成配置，并非跳过依赖就能运行。
配置已存在默认拒绝覆盖；明确要重建时加`-Reconfigure`。机器配置和生成物已加入`.gitignore`。

## 验证与出片

```powershell
pwsh -File scripts/video.ps1 -Command doctor
pwsh -File scripts/director.ps1 doctor --out .local/my-doctor.json
pwsh -File scripts/director.ps1 clip render --spec examples/director-smoke.json --out .local/my-first-clip
```

`smoke.ps1`实际渲染两个3秒、640×360、30fps的MP4：导演参数化动画与自定义Canvas源码，
分别检查90帧、尺寸、时长与完整解码；这是安装连通性测试，不是审美验收或完整能力认证。
每次使用新的输出目录，避免覆盖已有作品。

源码浏览器动画可提供`renderAt(t)`、`ready`和可选`stateAt(t)`，参考`examples/source-demo/index.html`。
入口spec由setup生成在`.local/source-demo.json`，含本机绝对路径，故不随仓库分发。

## 原声剪辑

下面列出入口帮助；输入文件与新输出路径按帮助中的参数填写：

```powershell
pwsh -File scripts/video.ps1 -Command rough-prepare -ToolArgs '--help'
pwsh -File scripts/video.ps1 -Command fine-cut-plan -ToolArgs '--help'
pwsh -File scripts/video.ps1 -Command stage-status -ToolArgs '--help'
```

粗剪可以显式导入已有逐词转写。自动ASR需另安装[whisper.cpp](https://github.com/ggml-org/whisper.cpp)，
在本机`runtime/video-workspace/config/video-workflow.json`里配置executable、modelPath、
modelSha256与jobsRoot；原生Whisper缓存/模型路径使用ASCII目录。转写仍须人工校对。
不提供TTS入口，也不要求用户提供声音克隆资料。

正式项目状态核心已随包提供，并由setup编译。相关合同与用法见
[核心README](../runtime/video-production-workflow/README.md)。本地独立剪辑不伪造正式项目审核状态。

## 可选视觉依赖

```powershell
pwsh -File scripts/setup.ps1 -WithOptionalVisuals -Reconfigure
```

会额外安装固定版本Three.js/p5/p5.brush、HyperFrames与LiveCanvas/Remotion模板依赖。
这些库的版本存在、浏览器图形探针通过、某个场景实际出片、用户认可画面，分别记录。
大部分素材搜索库、24家族背后的外部参考工程与作者私有原片没有打包；风格导航保留公开来源，不能据此声称所有参考片已具备。

## Skill中的旧路径
