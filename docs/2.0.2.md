# 2.0.2 · LiveCanvas渲染模板依赖安全修复

## 原因与范围

PostCSS间接依赖source-map-js的范围为`^1.2.1`，旧锁文件将它固定为1.2.1。该版本命中[GHSA-68fv-2mgg-jv7q / CVE-2026-93749](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)：处理恶意索引source map中的异常section偏移可阻塞事件循环。上游1.2.2已修复。这里确认的是分发依赖命中公告，不是对任何使用者设备已遭攻击的判定。

本次两份锁文件均只更新`node_modules/source-map-js`到1.2.2，连同下载地址和完整性校验更新。Remotion、React、模板package.json、场景与render脚本保持原样，无强制大版本升级。历史快照内仍可安装的模板也应用同一安全修订，并在NOTICE.md显式标注；sources.json保留原upstreamSha256和当前sha256。未删除原有技能、参考、历史入口或样片。

版本：jia-director 2.0.2；jia-motion保持2.0.1。

## 使用者如何更新

先通过原安装方式更新jia-director到2.0.2；Git克隆用户在干净工作区执行`git pull --ff-only`。若有自己的改动，先保存或提交，不能覆盖项目。

新工程从更新后的主模板创建，在模板package.json所在目录执行：

```sh
npm ci
npm audit --audit-level=high
```

已经把旧模板复制成独立工程的用户，更新Skill不会改其node_modules。请在该工程package.json所在目录执行：

```sh
npm update source-map-js --package-lock-only
# 核对锁文件差异；本次补丁应只涉及source-map-js，安全版本至少1.2.2。
npm ci
npm audit --audit-level=high
```

若是其他漏洞或依赖冲突，单独核对；不要运行`npm audit fix --force`自动跨版本升级，也不要关闭审计代替修复。此步骤只适用于本仓库的npm/Remotion模板，不是向所有视频工程批量安装此包。
