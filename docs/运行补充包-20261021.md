# 运行补充包 · 2026-10-21

补上此前Skill仓库未包含的`jia-director-system`和“视频剪辑skill”执行工作区，
以及后者依赖的项目状态核心。按用户明确要求，本次不上传TTS、音色克隆、
个人声音资料或模型权重。原声、字幕与音轨合成保留。

## 这次新增

- `runtime/jia-director-system`：Python CLI、动画引擎、字体与实际渲染资产、分镜/QA/合成/交付合同。
- `runtime/video-workspace`：原声粗剪与帧级精剪、审片UI、源码渲染适配、独立ASR接口、可选视觉工程。
- `runtime/video-production-workflow`：正式状态与审核合同核心，源码、schema、编译配置和测试。
- 根目录`setup.ps1`、`configure.py`和两个启动器：无需复制作者盘符；依赖安装和本机配置留在当前克隆。
- `smoke.ps1`：两条入口实际导出视频，检查真实帧数和完整解码。
- `verify-public-package.py`：原Skill字节、运行程序来源/改编、明确排除项与JS导入闭合检查。

`skills/`的176个发布文件保持2.0.2批准内容，未修改正式中央库或原本地项目。
公开版从根目录启动器接入，原Skill资料里的作者机器路径仅是历史运行位置。
