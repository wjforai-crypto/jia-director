# 2.0.1 · 生图按动态效果规划

## 已确认的制作要求

需要生图时考虑最终动作与场景效果。静态图好看、图集有若干格或文件输出30/60fps，均不足以证明动态效果成立。允许继续使用图像工具，素材规模与实现方法从镜头要求推导。

## 具体落位

| 环节 | 落位 |
|---|---|
| 导演决策 | 完整场景风格帧与风险代表段，包含真实背景与镜头 |
| H04/H05 | 人物、道具、背景统一；生图前规划姿态/动作相位或分层部件 |
| 分镜/提示词 | 动作相位、素材与代码分工、输出/姿态节奏、背景要求与实际检查点 |
| 动画执行 | 连续姿态、关节或混合方法；支点/重心/接触/循环及实际尺寸 |
| 审核与交接模板 | 技术、动作表现、背景美术、连续观看与本人接受分别记录 |

姿态数量、背景层数和动作更新节奏按画面目标选择。示例数量仅用于起步试验，像素、定格、UI等风格不强套同一动作频率或物理规范。原有选型与人工审片节点继续使用，不新增逐张生图审批。

## 本次变更边界

更新导演包4个文件、动画包6个文件；未删除原有内容，历史入口与风格资料保留。渲染器及自动质量算法未修改，新增美术字段不是自动美术评分。现有视频按原版本保存，用户对动作与背景的不满意不因技术通过而消失。
